### 1. scProtoTransformer: Scalable reference mapping across molecules, cells, and donors.

- 证据类型: 同行评审
- 原始链接: https://pubmed.ncbi.nlm.nih.gov/42664347/
- 来源: `Science Advances`
- 发布日期: `2026-08-28`
- 分类: 单细胞基础模型；细胞图谱与数据底座
- 事实性简述: scProtoTransformer 把 single-cell reference mapping 从 gene、cell 延展到 donor 层级，并显式引入 foundation model 蒸馏知识与生物学 pathway prototypes，目标是在保持可解释性的同时提升跨层级映射的可扩展性。
- 方法与数据: 根据 PubMed 原始 XML 摘要，模型使用 knowledge-guided prototype tokenizer 将 gene expression 投影到可解释 pathway prototypes，以减少数值 batch effects 并保留 biological semantic patterns；再结合 foundation model distilled knowledge 和 dynamic supervised fine-tuning，在分子、细胞和 donor 三个层级做 reference mapping benchmark。
- 主要结果: 原始摘要称，scProtoTransformer 在分子、细胞和 donor-level reference mapping 上达到与现有 state-of-the-art 方法相当或更优的表现，并通过 biological prototypes 提供解释能力。
- 局限与证据边界: 当前可直接核验信息主要来自 PubMed 摘要，尚未在本轮检索中补到完整正文、代码链接和全部 benchmark 数值表，因此不能夸大其通用性或解释深度。
- 与主线关联: 它直接命中单细胞基础模型与 atlas 映射主线，是本轮最重要的正式发表更新。

### 3. Hi-Cformer enables multiscale chromatin contact map modeling for single-cell Hi-C data analysis.

- 证据类型: 同行评审
- 原始链接: https://pubmed.ncbi.nlm.nih.gov/42664339/
- 来源: `Science Advances`
- 发布日期: `2026-08-28`
- 分类: 多组学与调控；测序与方法学
- 事实性简述: Hi-Cformer 是针对 scHi-C 稀疏接触图的 transformer 方法，试图同时建模近对角强信号和多尺度染色质结构，从而得到更稳健的单细胞表征、插补结果和注释能力。
- 方法与数据: 根据 PubMed 原始 XML 摘要，Hi-Cformer 通过 specialized attention mechanism 同时建模多尺度 contact-map blocks 与跨基因组区域依赖，从 sparse scHi-C 数据中学习低维 cell representations，并用于 chromatin interaction imputation 和 cell type annotation。
- 主要结果: 原始摘要称，Hi-Cformer 比现有方法更好地区分细胞类型，且能更准确插补 TAD-like boundaries、A/B compartments 等与细胞异质性相关的染色质相互作用信号。
- 局限与证据边界: 当前主要依据 PubMed 摘要核验，尚未补到完整基准表、计算成本和代码发布细节；因此它应被视为高相关方法学更新，而不是已广泛验证的基础模型平台。
- 与主线关联: 它直接补强单细胞调控组学与跨模态细胞状态建模底座。

### 4. st2traj: deconvolution-informed trajectory inference for multi-timepoint spatial transcriptomics.

- 证据类型: 同行评审
- 原始链接: https://pubmed.ncbi.nlm.nih.gov/42658029/
- 来源: `Bioinformatics`
- 发布日期: `2026-08-27`
- 分类: 空间与时空组学；测序与方法学
- 事实性简述: st2traj 面向多时间点空间转录组轨迹推断，把 deconvolution 得到的 spot-state composition 作为主输入，避免直接拿 spot-level expression 硬做跨时间轨迹。
- 方法与数据: 根据 PubMed 原始 XML 摘要，作者先在 human heart pseudo-spot benchmark 中比较五种 deconvolution methods，再用 DECODE-derived proportions 在 multi-timepoint human heart 数据上做 trajectory inference，并与 spaTrack、moscot、CASCAT 做探索性比较；GitHub 代码和 Zenodo 数据已在摘要中给出。
- 主要结果: 原始摘要称，未缩放的 DECODE-derived proportions 能产生更平滑的 trajectory fields，并与 expression-derived marker programs 更一致；st2traj 的空间一致性也优于 spaTrack，在独立 chicken heart 数据上恢复了阶段相关轨迹变化。
- 局限与证据边界: 当前可直接核验信息仍主要来自 PubMed 摘要，尚未补到全部量化指标和多平台 benchmark，因此不能过度外推其泛化范围。
- 与主线关联: 它属于空间与时空组学高相关方法更新，会直接影响时序空间图谱与动态模型评测。
