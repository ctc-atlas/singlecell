### 1. PopPert：群体联合分布驱动的单细胞扰动预测

- 标识: `arXiv:2609.01357`
- 证据类型: `预印本`
- 原始链接: https://arxiv.org/abs/2609.01357
- 发布日期: `2026-09-01`
- 分类: `虚拟细胞与扰动`、`单细胞基础模型`
- 简报: PopPert 把单细胞扰动预测从假设 cell-to-cell correspondence 的单细胞级建模，转向直接参数化 control population 与 perturbation condition 下的联合表达分布，更贴近真实 unpaired Perturb-seq 观测设定。
- 方法与数据: 根据 arXiv 原始摘要，模型输入 control population distribution 和 perturbation condition，预测扰动引起的分布参数变化，并用 low-rank Gaussian Copula 建模跨基因统计依赖，支持采样 synthetic perturbed single-cell profiles。
- 主要结果: 作者在覆盖 genetic 与 chemical perturbations 的多个 single-cell benchmarks 上，报告在 differential expression recovery、perturbation effect estimation 和 population-level distribution matching 上获得整体更优表现，并已公开代码仓库。
- 局限与边界: 当前仅能从 arXiv 原始摘要确认总体任务设定、核心建模结构与作者声称的优势，尚不能确认全部 benchmark 组成、量化指标细节和训练成本。

### 2. PROSPECTor：跨单细胞表示空间的开放式发现框架

- 标识: `arXiv:2609.00681`
- 证据类型: `预印本`
- 原始链接: https://arxiv.org/abs/2609.00681
- 发布日期: `2026-09-01`
- 分类: `单细胞基础模型`、`测序与方法学`
- 简报: PROSPECTor 不是再训练一个单细胞 foundation model，而是把 conventional expression representations 与 foundation-model embeddings 上的开放式生物发现流程做成了可审计、可外推的 end-to-end framework。
- 方法与数据: 根据 arXiv 原始摘要，框架先在多种表示空间中搜索可重复 biological structures，再把这些信号转译成可定量检验的 candidate hypotheses，并通过 projection 到 unseen datasets 评估泛化性与 phenotype association。
- 主要结果: 作者报告 fibroblast extracellular-matrix programmes 可迁移到独立小鼠干预队列，patient-resolved gastric-cancer T-cell programme 可在 single-cell、bulk 与 spatial cohorts 中复现。
- 局限与边界: 当前仅能从 arXiv 原始摘要确认框架目标与代表性验证案例，尚不能直接核验统计控制、筛选阈值、对照流程和代码可用性。

### 3. 亚细胞分辨率单细胞嵌入学习

- 标识: `arXiv:2609.02344`
- 证据类型: `预印本`
- 原始链接: https://arxiv.org/abs/2609.02344
- 发布日期: `2026-09-02`
- 分类: `单细胞基础模型`、`多组学与调控`
- 简报: 该预印本把 single-cell embedding 从整细胞级向量推进到 subcellularly resolved 表示，同时联合 RNA expression、protein sequence representation 与 protein structural information，并按不同亚细胞区室建模。
- 方法与数据: 根据 arXiv 原始摘要，作者采用 cross-attention architecture，在 distinct subcellular compartments 内整合 transcriptomic、sequence 和 structural modalities，输出包含细粒度亚细胞组织信息的 cell embeddings。
- 主要结果: 原始摘要称，该框架可在同一表示中同时保留分子表达模式与蛋白功能属性，并将其定位为首个把 transcriptomic、protein sequence 与 protein structural knowledge 共同纳入 subcellularly resolved cell embeddings 的统一框架。
- 局限与边界: 当前仅能从 arXiv 原始摘要确认模型设计与作者声明的创新点，尚不能直接核验 benchmark 数据、对照基线、下游任务指标和代码发布状态。

### 4. COBRA：面向 cell-type-specific batch effect 的正式发表方法

- 标识: `PMID:42684056` / `10.1093/bioinformatics/btag660`
- 证据类型: `同行评审`
- 原始链接: https://pubmed.ncbi.nlm.nih.gov/42684056/
- 发布日期: `2026-09-02`
- 分类: `测序与方法学`、`单细胞基础模型`
- 简报: COBRA 是正式发表在 Bioinformatics 的单细胞批次校正方法，核心改进是显式调整 cell-type-specific batch effect，并避免只在低维空间内修正导致的信息损失。
- 方法与数据: 根据 PubMed 原始 XML 摘要，COBRA 是 linear model-based batch correction method，通过将 batch-associated parameters 相对 biological variables 做正交化来移除技术伪影；若缺少 cell type annotation，则迭代估计 pseudo-cell types 并同时处理 batch effects，且保留完整 gene expression matrix。
- 主要结果: 原始摘要称，作者在 simulated 与 real-world datasets（包括 type 2 diabetes 和 COVID-19）上评测后，COBRA 在 batch mixing efficiency、biological group structure preservation 和 differentially expressed gene detection accuracy 上表现更优；代码与 Zenodo 复现资源已公开。
- 局限与边界: 当前可直接核验信息主要来自 PubMed 原始摘要，尚不能确认全部对照方法、不同细胞组成偏移情形下的稳健性边界和计算成本。

### 5. scPyviewer：AnnData 原生单细胞交互查看器

- 标识: `10.64898/2026.08.26.747418`
- 证据类型: `预印本`
- 原始链接: https://www.biorxiv.org/content/10.64898/2026.08.26.747418v1
- 发布日期: `2026-08-31`
- 分类: `测序与方法学`
- 简报: scPyviewer 面向 Python/scanpy 用户长期缺少原生、可分享单细胞交互查看器的问题，直接摄取 AnnData 并提供 web app 与 Python API。
- 方法与数据: 根据 bioRxiv 原始摘要页，作者将其与三款活跃维护的 R Shiny 单细胞查看器做 feature-parity audit，并在 22,315 到约 313,000 细胞的三套数据上，对底层渲染性能进行 head-to-head benchmark。
- 主要结果: 原始摘要称，scPyviewer 在功能覆盖上达到或超过全部基线能力（7/7），且是其中唯一原生支持 AnnData、无需 Seurat conversion 的方案；在三套数据上核心视图渲染都更快，单视图最高约 3.6 倍，同时内存占用更低，在最大数据集上 Seurat 渲染底座因 8 GB 内存预算失败而 scPyviewer 仍可完成全部视图。
- 局限与边界: 当前仅能从 bioRxiv 原始摘要页确认软件定位、基准比较和公开代码状态，尚不能直接核验更细的交互延迟定义、部署边界和跨浏览器稳定性。
